# Changelog

All notable changes to Veterinary Clinic are documented in this file.

This project uses semantic versioning for public releases. New entries are added
by `npm run version:bump`, which keeps package metadata, AppStream metadata and
this changelog aligned.

## 0.2.0 - 2026-07-09

### Highlights

- Prepared Veterinary Clinic for single-client production testing.
- Added the first Linux packaging metadata required by desktop software centers.

### Added

- Linux AppStream metadata for distribution catalogs.
- Desktop integration metadata for Linux bundles.
- Root license files included in generated packages.
- Initial public release notes used by the packaging pipeline.

### Packaging

- Added AppImage and Debian package metadata.
- Registered package copyright and license information.
- Added release metadata consumed by Linux software centers.
